# Wiki.js

Wiki.js (moderne Wiki-Software) mit PostgreSQL.

## Start

```bash
docker compose up -d
```

## Umgebungsvariablen (`.env`)

| Variable | Beschreibung |
|---|---|
| `POSTGRES_DB` | Name der Datenbank |
| `POSTGRES_USER` | Datenbank-Benutzer |
| `POSTGRES_PASSWORD` | Passwort des Datenbank-Benutzers |
